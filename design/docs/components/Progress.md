Barra de avance, usada para las unidades elegidas de un pack.

- Implementación: `app/src/components/ui/Feedback.tsx`. Clases: `pasto-progress`.
- Props: `value`, `max` y `label` (nombre para lectores de pantalla). Expone `role="progressbar"` con sus valores.
- Va siempre acompañada de un texto con el número ("3 de 5 unidades"). El color no es la única señal.
